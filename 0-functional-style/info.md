# Functional programming style

* The role of functions
    * mapping input to output (as opposed to "doing something")
    * declarativeness vs imperativity
    * functions as "first-class citizens"
    * anonymous function (lambdas, function literal)
    * higher-order functions: map, filter, etc. – "named" loops
* Additional features commonly associated with the functional style:
  * embracing immutability
  * constructing data with basic operations (algebraic data types):
    two things together OR one of two alternatives
  * elaborated type systems (not necessary)
  * pure functions, side effects and effect management
* There many functional programming languages: Haskell, OCaml, LISP, Clojure, etc.
* Most of the modern programming languages support functional programming style.
